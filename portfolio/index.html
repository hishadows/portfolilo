Pathy, the WhatsApp bot

Post a ride by just texting

People type the way they talk — "anyone going niagara tmrw?? need ride from welland". Pathy is an AI agent that understands messages like that, asks only for what's missing, saves the ride with map coordinates and tells you who's going your way.Live

  • Asks every missing detail in one message, not five
  • Never shares anyone's name or number — sends a safe link instead
  • Only replies when you message it, so it costs nothing to run

Exit 5

The automation engine

n8n workflows that run while I sleep

Behind every bot reply is a chain of small steps: read the message, pull out the details, find it on a map, save it, find matches, reply. I build these chains in n8n on my own server. Type a ride message and run it.

  • Self-hosted on a free cloud server — no monthly fees
  • One router sends every message to the right workflow, no mix-ups
  • The same pattern works for bookings, leads, invoices or support
